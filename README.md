# סמכויות בסיעוד

אפליקציית אינטרנט בעברית, מותאמת לנייד ולמחשב. מסך הסמכויות האישיות מסנן את הכרטיסים שמופו לפי מחלקה והכשרה. מסך החיפוש מאפשר חיפוש חופשי וסינון לפי נושא, סוג פעולה, מחלקה או הכשרה.

## הפעלה מקומית

מהתיקייה של המאגר:

```sh
python3 -m http.server 8000
```

פתחו את http://localhost:8000 בדפדפן. האפליקציה סטטית וללא התקנת תלויות. הפרופיל נשמר מקומית בדפדפן.

## תוכן רפואי ותחזוקה

גרסת ההדגמה כוללת מבחר מתוך חוזרי מינהל האחיות. הכרטיסים ב־`catalog.mjs` כוללים קישורים לעמודים ולסעיפים במקורות. כרטיס עם `pending: true` מוצג כהפניה לבירור ומוחרג מתוצאות הסמכויות האישיות. העדר תוצאה במאגר חלקי אינו קביעה לגבי הסמכות.

`requirements` מכיל קבוצות הכשרה. נדרשת לפחות הכשרה אחת מכל קבוצה. רישום כאחות מוסמכת הוא בסיס לכל הכרטיסים. הכשרה אישית שהוזנה חופשי נשמרת בשם שהוזן ואינה משמשת לחישוב התאמה.

חוזר 263/2026 משמש כמפתח ריכוז. לפני פרסום לצוות נדרשת השלמת הכרטיסים, בדיקה מול גרסאות המקור התקפות ואימות מוסדי של הנוסח בדבר אישור האחות האחראית ושל מנגנון ההרשאה. הדרישה לוודא אישור מול האחות האחראית מוצגת לפי אפיון המוצר ואינה מיוחסת לסעיף בחוזרים. האפליקציה אינה מעניקה או מאמתת הרשאה אישית.
